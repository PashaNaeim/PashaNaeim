Web Developer and Designer
--------------------------

I am a Web Developer and WordPress Specialist with experience in building modern, high-performance websites and web applications. My core expertise is WordPress development, combined with PHP, HTML, CSS, and JavaScript to create custom themes, plugins, and scalable solutions.

Beyond WordPress, I work with modern web technologies such as React, enabling me to build dynamic, interactive user interfaces and integrate them seamlessly with backend systems. I focus heavily on performance optimization, SEO best practices, and clean code, achieving fast load times (under 2.5 seconds) and Google PageSpeed scores above 90.

I develop responsive corporate and e-commerce websites with a strong emphasis on UI/UX design, usability, and maintainability—delivering products that are both visually appealing and technically robust.
